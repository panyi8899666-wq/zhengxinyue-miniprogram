# 正鑫越文化传播个人工作室 · 作品集小程序

微信小程序源码，复刻作品集网站的内容与设计（墨黑 #0D0D0F / 炭灰 #141416 / 象牙白 #ECEAE4 / 香槟金 #C6A15B，克制高级暗色）。

2026-10-16 与网站最新版同步：首页居中大标题「设计不只好看，更要让品牌被记住」、精选案例纯图卡片、「从策略到落地」板块、服务能力四项、时间轴履历、案例详情深色数据风；联系页仅邮箱（过审要求）。

## 微信开发者工具导入步骤

1. 前往 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序（建议用工作室的个体户/企业主体；类目建议选"设计服务"或"广告/会展服务"）。
2. 注册完成后，在「开发管理 → 开发设置」拿到 **AppID**。
3. 打开微信开发者工具 → 导入项目 → 选择本目录 `miniprogram-zhengxinyue/`。
4. 把 `project.config.json` 里的 `"appid": "wx0000000000000000"` 替换为你的真实 AppID（或在导入时填入）。
5. 点击「编译」，在模拟器里预览全部 5 个页面。

## 提交审核注意事项

- **类目**：选择与设计服务相关的类目；避免选"社交""金融"等需特殊资质的类目。
- **服务内容**：小程序内只有作品展示、价格说明、联系咨询，无在线支付、无用户生成内容，审核风险低。
- **隐私**：「一键咨询」表单只在本地生成需求单文本、由用户手动复制发出，不上传服务器；如微信要求，可在后台「设置 → 服务内容声明」如实填写。
- **真实项目标注**：真实客户项目标注"真实客户项目 · 实际交付"，真实个人作品标注"真实个人作品"，其余为概念案例，提审描述里保持一致口径。
- **域名**：如图片放在自有域名，需在小程序后台「开发管理 → 服务器域名」配置 `request` 合法域名（仅 HTTPS）。
- 首次提审建议先用「体验版」发给自己手机实测一遍，再点「提交审核」。

## 已知限制

- 图片地址为空时所有图片位为占位样式，需填入 `IMAGE_BASE_URL` 后才显示真实图片。
- tabBar 图标为程序生成的简易几何图标，可替换为设计师精修版（81×81px PNG）。
- 案例数据为网站内容的静态复刻；网站后续更新案例后，需同步修改 `data/cases.js`。
- 「一键咨询」为本地表单（无后端），需求单靠用户复制发出；如需自动推送到手机，需另接客服消息/模板消息能力（需企业主体与后端支持）。
